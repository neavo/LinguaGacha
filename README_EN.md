## Overview 📢
- [LinguaGacha](https://github.com/neavo/LinguaGacha) (/ˈlɪŋɡwə ˈɡɑːtʃə/), a next-generation `AGENT Harness` specialized in translation
- `One-Click`
  - Fully automatic one-click translation across languages
  - Drop it in, hit start, get ready-to-enjoy results
  - No technical background or foreign language knowledge required
- `High Quality`
  - Unbound by model censorship, free output
  - Automatically builds a glossary to keep proper nouns consistent throughout the work
  - Fully preserves formatting and styles across `Subtitles`, `E-books`, and `Game Engines`
  - Semantic smart proofreading: just point out the issue and `AGENT` automatically corrects and polishes the translation
- `All Formats`
  - Translate virtually anything, including but not limited to:
  - Audio & Video - `ASMR`, `Anime`, `TV & Film`, `Dynamic Comics`, and more
  - Subtitles & E-books - `.txt`, `.md`, `.epub`, `.pdf`, `.srt`, `.ass`, `.ssa`, `.vtt`, `.lrc`, and more
  - Game Engines & Data Files - `Godot`, `ACTION GAME MAKER`, `RenPy`, `Tyrano`, `WOLFRPG`, `RPGMAKER`, `KV-JSON`, `Message-JSON`, and more

## Basic Workflow 🛸
- Download application from [Releases page](https://github.com/neavo/LinguaGacha/releases)
  - Windows:
    - Download `*_Windows_x64.zip` or `*_Windows_arm64.zip` according to your CPU type
    - Extract it and double-click `app.exe` to launch
  - <details>
    <summary>macOS:</summary>
    - Download `*_macOS_x64.dmg` or `*_macOS_arm64.dmg` according to your CPU type
    - Drag it to the Applications folder, but do not launch it yet
    - Open Terminal, enter `sudo xattr -rd com.apple.quarantine /Applications/LinguaGacha.app`, then press Enter
    - Enter your system password, close Terminal, and you can launch it normally
    </details>
  - <details>
    <summary>Linux:</summary>
    - Download `*_Linux_x64.AppImage` or `*_Linux_arm64.AppImage` according to your CPU type
    - Add executable permission with `chmod +x LinguaGacha*.AppImage`
    - Run `./LinguaGacha*.AppImage`
    </details>
- Obtain access to a reliable AI model API, such as [ [DeepSeek](https://github.com/neavo/LinguaGacha/wiki/DeepSeekEN) ]
- Launch the app, create a project, drag your `files to translate` into the `AGENT` input box, and press Enter!

## Development Guide 🛠️
- Install [Go](https://go.dev) and [`Node.js`](https://nodejs.org)
- Install dependencies `npm install`
- Update dependencies `npm ci`
- Run the application `npm run dev`
- Build the release `npm run build`
- Before submitting a PR, run the corresponding checks in [`docs/WORKFLOW.md`](./docs/WORKFLOW.md) based on the scope of your changes
- For non-developers, please download the packaged version directly from the [Releases page](https://github.com/neavo/LinguaGacha/releases)
