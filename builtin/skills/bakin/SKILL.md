本技能只提供 RPG Developer Bakin 引擎知识。导入、通用数据封装与写回按 `project-operation` 和 `generic-data` 执行，翻译与审校按 `translation` 执行。

内置解析器不识别 Bakin 游戏，文本都经通用数据进入工程。

# 识别

|特征|含义|
|---|---|
|`data.rbpack`|主数据容器，内含 `BKNPAK` 资源表|
|`.rbr` 记录|地图、事件、数据库等原生记录|
|`bakinplayer.pak`|ZIP 格式，启动器从中解压并覆盖播放器 EXE 和 DLL|

播放器基于 .NET，原生类型在 `Yukar` 命名空间下，可通过程序集反射读取和写入记录。

# 无损往返

以下情况会使未改动的往返与原文件不一致：

- 某些对象的读取与树关联是两步。例如公共事件列表读取后，需要用目录调用 `initialize` 恢复子文件夹关联再保存，直接读取后保存会丢失子文件夹。无法完整恢复时，保留该子块的原始字节。
- 读取器返回后剩余的尾部字节和非目标子块原样保留。
- 重建容器时核对资源表中每项的名称、顺序、长度、偏移和压缩标志。

# 文本来源

底层字符串读取会同时命中资源路径、内部键和编辑器描述。按实际显示位置筛选：对白、选项、数据库说明、布局菜单、地点名、系统词汇和标题。

- 游戏内标题 `GameSettings.meta.title` 与桌面窗口标题不同。窗口标题来自 `GameSettings.name`，一并提取。
- 顶部工具栏菜单可能在 `kmyCore.dll` 或 `kmyWindowsCommon.dll` 的 Windows 菜单资源中。按实际菜单层级和命令 ID 修改标题，保留助记符 `(&X)`、字面量 `&&` 和制表符后的快捷键。

# 变量与控制符

- `\$[key]` 是命名变量引用，方括号内即使含源语言文字也是查找键，整段保持原样。只保护反斜杠加字母的控制符会漏掉它。画面数值变成空白时，先检查变量键是否被翻译。
- 字符串变量可能同时用于显示和条件比较。改动变量值或比较常量会破坏分支和旧存档。

# 写回与交付

- 只修改松散的播放器文件会在启动时被 `bakinplayer.pak` 还原，需同步更新包内的对应文件。
- `defaultLayoutFont` 与 `defaultMessageFont` 分别控制布局和对白字体，布局节点也可能单独指定字体。替换字体前确认字体记录是否被多处共享，检查译文字符集覆盖，保留字号和其他参数。
- 通过反射修改布局中 `Vector2` 等嵌套值类型后，把修改后的值重新赋给父对象字段再保存。

# 覆盖缺口

交付时只向用户说明本游戏满足条件的项：

|条件|向用户说明|
|---|---|
|未处理原生菜单资源|顶部菜单仍为原文|
|替换或调整了字体与布局|需要在游戏中确认界面显示正常|
