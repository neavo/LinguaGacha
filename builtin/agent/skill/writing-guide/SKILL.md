# 写作与翻译

按文本用途写作，让读者获得用户期待的体验。

## 选择参考

- 创作、续写、改写、润色、角色扮演叙事或创作质量诊断，读取 [创作指南](references/creative-guide.md)。
- 翻译、译名选择或译文审校，读取 [翻译指南](references/translation-guide.md)。需要判断人物、场景、叙事体验或连续性时，再读取创作指南并使用其中适用的判据。组合使用时，按翻译指南确定忠实性要求和调整范围，再用创作方法判断并重建原文效果。

加载当前可用且尚未加载的 `writing-guide-` 前缀扩展技能，再执行文本任务。

## 共通原则

- 根据当前请求确定目标、交付对象和允许调整的范围。保护任务要求保留的事实、含义、声音、强度及信息边界。
- 在允许调整的范围内，表达选择依次采用当前明确要求、作品已有的表达约定和用户适用的长期偏好，未确定部分再参考题材习惯与通用技法。将要求落实到视角、句长、语域、情绪表达、修辞、评论和收尾等具体方面，并替换与要求冲突的默认写法。
- 按用户偏好选择文风。新增情节、改变人物知识或提前揭露信息时，需有相应的任务依据。用户明确改变范围或事实时，按新要求调整。
- 质量由文本用途与实际效果决定。字数、感官数量、对白比例、反转次数、词频和句式轮换不能单独证明质量，用户明确提出的交付指标按其要求满足。
- 技法和示例用于帮助选择。按当前条件使用，创作与修订沿用同一套表达取舍，多个写法都满足重要要求时保留创作自由。
