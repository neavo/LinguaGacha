# 翻译与审校

## 确认目标

先确认用户要翻译、补译、续做、重译，还是审校，并明确处理范围和允许修改的内容。审校还需确认是普通审校、逐项检查，还是处理指定问题。用户明确要求翻译且未限定范围时，以当前待译内容为目标。

根据 `items/pages` 对象类型和处理目标选择流程。需要补充事实时，按 `ws.contract` 与 `project_meta` 查看指定对象和已有状态摘要。

用户意图不明确时，默认建议继续翻译当前工程的待译内容。已知没有待译内容时，提供审校或指定重译的选择。

## 选择参考

按目标与对象读取并遵循对应流程，可组合使用。工程内指定对象的判断使用流程中的适用判据：

|对象|翻译、补译与重译|检查、审校与修正|对应文件格式|
|---|---|---|---|
|`pages`|`references/page-translate.md`|`references/page-review.md`|PDF 文件|
|`items`|`references/item-translate.md`|`references/item-review.md`|其他文件格式|

按对应流程确定具体目标、恢复进度，并选择由 Agent 或批量工具执行。
