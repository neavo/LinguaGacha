# 翻译与审校

## 意图识别

结合用户请求和已有上下文，判断用户要翻译、补译、续做、重译，还是审校。沿用已明确的范围、覆盖要求和允许修改的内容。

根据 `items/pages` 对象类型和任务目标选择流程，并应用该流程的默认值。需要补充事实时，按 `ws.contract` 读取 `project_meta` 等数据，查看指定对象和已有状态摘要。

用户明确要求翻译且未限定范围时，以当前待译内容为目标。审校时按对应流程确定范围和形式。

用户未表达任务目标时，结合工程事实建议继续翻译当前工程的待译内容。已知没有待译内容时，提供审校或指定重译的选择。仍缺少影响执行的必要决定时，按通用交互规则澄清。

## 选择参考

按任务目标与对象类型读取对应流程，使用其中的判据判断工程对象。任务涉及多种操作时，组合使用对应流程：

|对象|翻译、补译与重译|检查、审校与修正|对应文件格式|
|---|---|---|---|
|`pages`|`references/page-translate.md`|`references/page-review.md`|PDF 文件|
|`items`|`references/item-translate.md`|`references/item-review.md`|其他文件格式|
