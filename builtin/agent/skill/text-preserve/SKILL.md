# 文本保护

## 意图识别

结合用户请求和已有上下文，判断用户要核验保护结构或表达式、修改指定值、提取遗漏规则，还是整理已有规则。沿用已明确的调查范围、修改范围和可读取语境。

选择流程需要补充事实时，按 `ws.contract` 查看指定对象、原始 `items`、保护规则和相关数据。

用户未表达任务目标时，结合工程事实建议提取遗漏规则并整理现有保护规则。仍缺少影响执行的必要决定时，按通用交互规则澄清。

## 选择参考

- 查询、解释或判断：读取规则判据 `references/rule.md`。
- 按用户指定值修改：读取规则判据，核对必要约束后按通用工程步骤提交。
- 调查、提取或整理：读取并遵循 `references/rule.md` 和 `references/workflow.md`。定点任务按用户指定的范围执行。

需要程序取证时读取 `references/scripts.md`，使用本包脚本及共享数据模块。
