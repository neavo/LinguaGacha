# 文本保护

## 确认目标

先确认用户要判断保护结构或表达式、修改指定值、提取遗漏规则，还是整理已有规则。明确要调查和修改哪些对象，以及可以读取哪些语境。

需要补充事实来选择流程时，按 `ws.contract` 查看指定对象、原始 `items`、保护规则和相关数据。用户意图不明确时，默认建议提取遗漏并整理现有保护规则，再根据工程事实调整建议。

## 选择参考

- 查询、解释或判断：读取规则判据 `references/rule.md`。
- 按明确指定值修改：读取规则判据，核对必要约束后按通用工程步骤提交。
- 调查、提取或整理：读取并遵循 `references/rule.md` 和 `references/workflow.md`，定点任务在指定边界内执行。

需要程序取证时读取 `references/scripts.md`，使用本包脚本及共享数据模块。
