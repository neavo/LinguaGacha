# 技能编写与安装

根据任务读取对应参考：

- 编写、修改或适配技能时，读取 [技能编写指南](references/authoring.md)。
- 安装、导入或替换技能包时，读取 [技能安装指南](references/installation.md)。
- 创建并安装技能时组合使用两份参考。导入中发现需要适配时，补读编写指南。

## 完成标准

依据用户要求交付有效的技能内容或完成安装，区分格式有效、已加载与运行验证通过。交付说明技能名称、实际完成的结果、验证依据及未满足的运行条件，并说明使用方式和启用状态。
