# 译文领域判据

## 技能协作

加载并遵循 `writing-guide` 技能。

本技能负责单个 item 的译文判断与字段形成。

## 1. 领域对象与证据

item 是不可拆的译文对象；`dst` 对应正文，`name_dst` 对应姓名槽位，`status` 只表达人工处置。源文本、质量规则和工程结构作为只读事实参与判断。

发生取舍时依次保护：

1. 用户明确要求；
2. 原文事实、信息量、不确定性、逻辑和表达意图；
3. 控制符、占位符、标签、转义序列、换行与其它保护边界；
4. 已确认的术语、姓名和实体身份；
5. 语境能够证明的说话人、指代、人物关系、视角、知识边界和剧情连续性；
6. 工程内已经成立的作品风格与目标语言惯例。

后项服务于前项。工程内的决定性反例优先于一般语言经验。警告提供待核验问题的定位与补证入口；最终处置由原文、工程约束与必要语境共同决定。

## 2. 一对一映射与结构

- 一条可回写源文本对应一个译文值，沿用原有顺序、行数、换行和条目边界；用户明确改变结构时按其要求处理。
- 每个条目的内容在本条目内完成，跨条目语境只提供判断证据。
- 控制符、占位符、标签、转义序列、格式脚手架、分隔符和已确认的保护结构逐字保持原有位置与边界。
- 结构边界仍需补证时保留已确认部分，并标记决定性缺口。

## 3. 姓名、术语与语境

- 姓名槽位承载姓名译文，称谓、头衔、敬称后缀和解释文字留在对应正文位置。
- 已有可靠姓名译名时保持同一写法；姓名栏、正文引用、别名和身份关系共同提供一致性证据。
- 形成译文前复用当前事实中与原文匹配的 glossary 应用；完整应用证据存在时直接使用，否则定点匹配相关条目。
- glossary 的条件说明决定译名适用语境；其它义项按上下文和原文功能翻译。
- 邻近文本只补充当前 item 判断所需的说话人、指代、关系、视角、知识和连续性事实。

## 4. 译文形成

先保留原文含义、语气、强度、视角、人物声音、有意歧义、信息时机和文本功能，再让译文在目标语言中自然成立。内容等价的多个方案依据用户要求、作品风格、同类已确认译文和目标语言习惯选择。

原文的粗粝、不规则、暧昧或令人不适之处按其实际功能保留。译文自然度通过准确的关系、语域、节奏和表达方式实现，解释性信息由相应字段或上下文承载。

## 5. 处置结论

每个进入翻译或审查的 item 形成唯一结论：

|结论|适用条件|
|---|---|
|`update`|目标需要形成或改变译文，并且工程事实足以形成安全的新值|
|`keep`|已有译文符合要求，或现有证据支持维持当前值|
|`blocked`|目标需要形成或改变译文，但安全新值依赖缺失的决定性事实|

`update` 写明实际变化的 `dst`、`name_dst` 或人工状态；未变化字段保持省略。`blocked` 写明决定性证据缺口和所需补充事实。多个合理方案都满足高优先级目标时保留选择空间，由用户已声明标准或当前工程风格完成收束。

## 6. 判例

|工程事实|结论|
|---|---|
|保护占位符缺失，其正确位置由原文结构唯一确定|恢复占位符并形成 `update`|
|姓名栏已有可靠译名，正文对同一角色使用另一译名|按共同身份统一，并核验相关引用|
|术语应用给出明确目标译名，当前译文没有落实|形成 `update`|
|相似度警告存在，但原文信息、语气与功能均已保留|形成 `keep`|
|代词译法取决于工作区尚未提供的说话人身份|形成 `blocked` 并记录所需身份事实|
|逐词对应准确，但人物声音和原文功能明显丢失|在信息等价范围内重译并形成 `update`|
