# 质量规则领域判据

统一解释 glossary 与 text_preserve 的领域判据。规则维护只依据原始工程语料与规则事实，不依赖质量规则启用状态或文本处理设置；字段、工具、变更和匹配行为始终以当前工作区 contract 为准。执行创建或审查工作流时，任务协议由对应工作流技能与 `@skill(quality-rule-workflow)` 承载，本技能只提供判据。

## 管理边界

- `glossary` 承载普通翻译无法稳定推出的专有译法、身份、消歧和世界观事实。
- `text_preserve` 承载翻译过程中必须逐字保持的控制符、占位符和格式脚手架；只在文本保护模式为自定义时参与翻译，维护资格与生效状态互不影响。
- `pre_replacement` 与 `post_replacement` 不在管理范围；用户明确要求时作为独立任务按通用任务协议处理。
- 替换规则和 item 修改只作范围外观察，不进入当前候选、处置或变更计数。

## 事实与推演边界

每条现有规则或候选规则独立核验，只能进入一种事实状态：

- **需规则承载**：规则身份、边界和具体值已经确定，普通处理不能稳定得到目标行为。
- **无需规则承载**：普通处理可以稳定得到目标行为，或内容不属于当前 kind。
- **未决**：缺少一个会改变结论的具体事实；必须指出缺少什么。

不得以出现次数少、当前没有错误、当前未启用、现有规则长期存在或修改麻烦改变事实状态；零命中不能单独证明既有规则无效。

禁止翻译运行时效果推演：不模拟多条规则组合应用、先后顺序或译前译后文本，不把不同规则命中数相加为全局覆盖率。允许 glossary 从全部已核验事实重新构造最小充分集合；text_preserve 始终逐条独立核验，只在身份完全重复或保护边界直接冲突时共同处理。

## 判定目标

对已核验范围按以下优先级形成最终集合，后项不得牺牲前项：

1. 必要性：只收录需要规则承载的事实。
2. 正确性：边界、身份、译文和提示符合证据。
3. 充分性：全部需承载事实都有安全规则覆盖。
4. 作品风格：符合用户要求和工程语境。
5. 一致性：同一专名、同根形式和同类概念采用一致策略。
6. 最小性：满足前五项后，选择条目最少、原文边界总长度最短的安全集合。

最小性不能解释为规则越少越好；先满足充分性，才允许合并、缩短或删除。

## glossary 判据

术语必须承载至少一种普通翻译无法稳定推出的事实：专有译法、身份属性、消歧或作品世界观。身份、边界和值已确认的人名、别名、姓氏、地名、家族、组织，以及作品特有的物品、技能、生物或概念，默认需规则承载；只有具体证据证明普通翻译能够稳定得到唯一结果且无需身份或消歧时才推翻。普通称谓、职业和泛用词无需承载。

- `src` 是 `item.src` 或 `item.name_src` 中的精确连续字面量，不使用正则；只保留必要核心。
- `dst` 是固定译文。
- `info` 会随 glossary 进入翻译提示词，属于规则行为；只写影响译法、指代或消歧的最少已确认语义。优先写实体类型，角色在已确认时区分性别，只在必要时追加年龄、职业、阵营或特殊身份。不要写背景、证据、理由、例句或复述 `src` / `dst`。
- `info` 未知且不同取值会改变翻译时列为未决；不会影响翻译时允许为空。更新或重构规则时保留仍然正确的既有信息，不得静默清空或臆造。
- 已有译文、既有术语和大小写只作为待核验事实。
- 每个候选独立决定身份、边界和值，不因另一规则命中相同 item 改变事实结论。

证据优先级为用户明确指定、工程内多处语境、已核验同类规则、目标语言一般表达。风格标准从完整任务范围建立一次并全程复用；多个值均合理且缺少决定性证据时列为未决。

## text_preserve 判据

文本保护不承载语义，只保护必须逐字保持的非自然语言结构。

- 只扫描原始 `item.src` 并按 `\n` 拆行，不扫描 `name_src`。
- 每条 `src` 独立使用 `new RegExp(source, "giu")`。
- `text_type` 和文件只解释命中分布，不改变匹配结果。
- `info` 只供用户识别规则，不参与正则编译、匹配、覆盖或必要性判断。能确认结构身份时使用简短说明，如“角色名控制符”“HTML 标签”；保留仍然正确的既有说明，表达式含义改变时同步更新，无法可靠命名时允许为空。
- 非法、零长度、无界通配、嵌套量词回溯或会吞掉自然语言正文的表达式不得进入最终规则。
- 只有全部真实命中都是必须原样保留的非语义结构且边界足够窄，才判为需规则承载。

## glossary 词根合并判据

最终集合从全部需承载事实重新构造，不以现有条目为起点。合并为公共词根前，先以语境确认需要共同处理的形式确实语义相关；公共词根候选只描述字面重合，不证明语义关系或规则资格。

公共词根只有同时满足以下条件才采用：

- 候选本身表达全部相关形式共同的稳定概念，不只是偶然字符重合。
- 覆盖全部拟替代且需承载的形式。
- 一个词根规则的 `dst` 与 `info` 能承载必须统一的译法、身份、风格或消歧信息。
- 完整匹配集合没有表明会新增普通词或其它实体误匹配。
- 剩余普通文本能够与词根译法正确组合。

只有具体误匹配、不可组合译法、词根 `info` 无法承载的必要分支身份或消歧、或无权处理的范围外冲突可以支持额外保留完整形式。不得自动合并不同分支的自然语言 `info`；必要分支信息无法由词根和剩余普通文本安全表达时，不得只保留词根。

## 类型路由

1. 必须逐字保持的非语义结构属于 text_preserve。
2. 专有译法、身份、消歧或世界观事实属于 glossary。
3. 确定性源文或译文转换属于替换规则，本技能不处理。
4. 单一条目译文错误属于 item 修改，本技能不处理。
5. 无法确定主要归属时列为未决，不同时创建多种规则规避判断。

最终变更只包含已经确认且在当前范围内的 glossary / text_preserve；未决和范围外观察不进入 change。
