# 术语规则

统一解释什么是术语、什么值得收录，以及怎样形成正确、充分且最小的术语集合。本技能只提供领域知识，不独立确定工程处理范围，不写入项目；字段、工具、变更和匹配行为始终以当前工作区 contract 为准。

## 什么是术语

术语是普通翻译无法稳定推出、且会影响专有译法、身份属性、消歧或世界观理解的作品专有名称或概念。

- 「普通翻译无法稳定推出」是收录的必要条件：没有合理分歧风险的词，不需要规则承载。
- 四个影响支柱必须至少命中一个：专有译法（固定译名）、身份属性（性别、年龄、类型等）、消歧（同名异义或同形异指）、世界观理解（作品特有设定概念）。

工程中术语通过 glossary 条目承载：`src` 是术语原文，`dst` 是固定译文，`info` 是语义提示。本文档说「术语」时指 `src` 指向的实体；说「术语条目 / 规则」时指承载它的 `src → dst + info`。术语与承载它的规则是两层概念：是否值得收录由实体的四支柱决定，规则集合是否最小由后文的最小充分集合决定。

## 收录与判定目标

对当前已核验范围按以下优先级形成最终集合，后项不得牺牲前项：

1. **必要性**：只收录需要规则承载的专有译法、身份、消歧或世界观信息。
2. **正确性**：原文边界、语义身份、译文和提示必须符合已核验事实。
3. **充分性**：所有已核验且确实需要规则承载的专有信息都必须被最终集合覆盖；漏收和误收同样是质量问题。
4. **作品风格**：译名符合用户要求及语境能够证明的题材、时代感、语气和命名体系。
5. **一致性**：同一专名、同根形式和同类概念采用一致策略；有意区分必须有具体语境依据。
6. **最小性**：满足前五项目标后，依次选择条目数量最少、原文边界总长度最短的安全集合。

最小性不能解释为术语越少越好；只有先满足充分性，才允许合并、缩短或删除规则。

## 统一事实判定

创建与审校先忽略条目是否已经存在，把每个已核验事实判为且只能判为以下一种状态；之后再由全部事实构造规则集合：

- **需规则承载**：对象是已确认的专有实体或作品特有概念，原文边界和具体规则值可以确定；若没有 glossary，合理译者可能在译名、指代、属性或消歧上产生足以破坏一致性的分歧；且没有其它最终规则安全覆盖该事实。
- **无需规则承载**：属于泛用或描述性内容，普通翻译足以稳定得到所需结果，未承载必要身份或消歧信息，或已经被其它最终规则安全覆盖。
- **未决**：缺少一项会改变上述结论的具体证据。必须指出缺少的事实，以及它的不同取值会分别导向何种结论；不能因修改风险、证据整理成本或不愿行动而使用未决。

合理分歧风险是正向门槛，不要求分歧已经发生。对身份、边界和具体值已经确认的人名、别名、姓氏、地名、家族、组织，以及作品特有的物品、技能、生物或规则概念，默认推定风险成立并归入需规则承载；只有具体证据表明普通翻译会稳定得到唯一结果且无需身份或消歧信息，或其它最终规则已安全覆盖时，才推翻该结论。单次出现、译文暂时一致或尚无错误都不降低其必要性。普通称谓、职业和脱离设定也能稳定翻译的泛用词原则上无需承载。

收录判据只有上述两条：对象是否属于需规则承载、是否被最终规则安全覆盖。出现频率、首字母大写、姓名栏、特殊写法、已有译文、旧条目长期存在、改动数量或动作复杂度，都只用于发现事实或安排核验顺序，不能单独改变事实分类。零出现同理：既有条目可能为当前语料之外的内容预置，没有命中不能单独证明规则无效。

## 边界与语义身份

- 术语原文必须是已核验原文正文或原文姓名中的连续字面量子字符串，不用正则代替精确边界。
- 精准判定边界：只截取必要的连续字符，去掉修饰性称谓，只取核心名字（如「骑士艾琳」→ 艾琳、「黑木家族的族长」→ 黑木家族）。
- `info` 是语义提示字段，用于补充会影响译法、指代或用于消歧的简短信息，不写完整背景、理由、证据、例句，不复述 `src` / `dst`
  - 首选内容为实体类型（角色应区分性别），如 `女性角色` `男性角色` `姓氏` `组织` `物品` `技能` `魔物` `特殊概念` 等
  - 实体具有特殊性时在类型的基础上额外补充，如 `女性角色，魔法师` `男性角色，老年` `宗教组织` `姓氏，有时代指整个家族` 等

## 风格与证据

按以下顺序建立一次全局标准，高优先级证据覆盖低优先级证据：

1. 用户在当前任务中明确指定的译名或风格。
2. 工程内多处已核验语境共同证明的命名规律。
3. 现有术语中稳定、无冲突且符合语境的同类命名方式。
4. 当前目标语言的一般表达习惯。

现有术语和已有译文都是待核验事实，不能只因占多数就成为标准。能够确定具体更好值时形成变更；多个具体候选都合理但缺少决定性证据时列为未决。

## 最小充分集合

从已核验原文重新构造能够承载全部必要专有信息的集合；没有必要信息时最终集合为空。候选不局限于既有条目，可以从语义相关形式中提取位于开头、中间或结尾的公共连续词根。

公共词根同时满足以下条件时优先采用：

- 覆盖所有已核验且确实需要术语承载的目标形式。
- 不丢失必须统一的译法、身份、风格或消歧信息。
- 完整匹配集合和当前语境没有表明它会新增普通词或其它实体误匹配。
- 剩余普通文本能够与词根译法正确组合。

只有具体证据可以支持额外保留完整形式：

- 词根会命中普通词或其它实体。
- 剩余文本无法正确组合，或完整形式具有不可组合的固定译法。
- 分支承载词根无法表达的必要身份、风格或消歧信息。
- 当前任务无权处理的范围外冲突影响该分支。
