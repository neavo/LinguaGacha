# 虚构叙事规则

统一解释什么使虚构叙事成立，以及如何在多种合理写法中保护人物、世界、因果与阅读体验。本技能只提供创作知识，不独立确定任务步骤、交互格式、工程操作或持久化方式；调用技能对玩家权限、原作证据、状态和输出形式有更具体的契约时，以该契约为准。

## 质量优先级

发生取舍时依次保护：

1. 用户明确建立的核心体验、事实、边界和表达意图。
2. 已经成立的事件因果、人物知识、世界规则与时空连续性。
3. 人物的欲望、责任、价值、关系、自主性和变化轨迹。
4. 当前章节、场景或段落真实承担的叙事功能。
5. 视角、叙事距离、信息公开与语言声音的一致性。
6. 清楚、准确、有选择的细节以及与内容相称的节奏。
7. 金句、反转、奇观、修辞密度和表面新鲜感。

低优先级效果不得靠破坏高优先级事实取得。不要用固定字数、感官数量、对白比例、事件点、句式轮换、词汇配额或禁语表代替判断；这些指标只能描述容量或表面特征，不能证明质量。

## 核心体验与叙事承诺

- 把题材标签转化为读者会持续经历的具体体验。例如悬疑的核心可以是认知不断失稳，爱情可以是靠近必然暴露软肋，冒险可以是能力与代价同步扩大；同一题材允许完全不同的体验承诺。
- 让人物、冲突、信息顺序、叙事距离、感官选择和语言语域共同兑现核心体验。只有宣称“压抑”“浪漫”“黑暗”而其它层面没有响应时，标签没有实际作用。
- 区分用户明确要求、原文已经建立和模型自行选择的内容。前两者构成约束；自行选择的方案可以在更好地保护高优先级目标时重构。
- 让作品保留自身锋利、不规则和令人不安的部分，不把所有文本磨成同一种顺滑、电影化、抒情或励志声音。
- 让主题通过人物反复面对的选择与后果显现。不要让旁白替故事宣布主题，也不要为了深刻给普通场景强加哲理总结。

## 情节、章节与场景动力

### 因果与推进

- 让事件由人物目标、既有关系、世界压力、错误判断或先前后果触发。巧合可以制造处境，不能反复替人物作选择或解决主要矛盾。
- 用以下关系理解有效推进，而不是把它当作每章必须填满的模板：

  **欲望或责任 → 行动 → 现实反馈 → 重新解释 → 选择 → 代价与余波**

- 让反馈改变人物能够知道、拥有、相信、承诺或尝试的内容。只有活动增加而状态不变时，情节仍在原地打转。
- 让冲突来自同时成立却不能同时满足的需要、价值、责任或资源限制。阻力可以来自敌人，也可以来自身体、制度、误解、时间、羞耻、依恋、身份或人物自己的解决方式。
- 把升级理解为选择空间收窄、代价显形、关系卷入或旧办法失效，不等同于持续增加敌人、暴力和音量。
- 允许成功伴随代价、失败带来信息、拒绝改变关系、等待消耗时机。故事不必按奖励正确选择、惩罚错误选择的主持人逻辑运行。

### 章节功能

- 让章节承载一个可辨认的主要变化，并允许次要变化围绕它发生。主要变化可以属于处境、认知、关系、承诺、身份、资源或行动方向。
- 区分行动性章节与反应性章节。行动性章节让人物尝试改变外部处境；反应性章节让人物消化后果、重组理解、调整关系或形成新目标。反应不是停滞，行动也不必持续高强度。
- 根据因果需要选择时间跨度。实时展开适合关键选择和不可逆动作；概述适合重复劳动、路程和渐变；蒙太奇只保留能够证明变化的关键帧。
- 让章节与前后文通过未完成动作、感官余波、关系压力、道具状态、消息传播或目标变化相连，不强制使用相同意象或固定剪辑术语。
- 让伏笔先作为当下自然成立的物件、信息、习惯或关系事实存在；回收时兑现其既有因果，不靠事后补设定假装早有安排。

### 场景流动

- 把场景视为一个连续的压力环境。进入时已经存在人物欲望、局部目标、未解决关系或外部限制；离开时至少有一项条件真正改变。
- 用动作、对话、环境反馈和人物重新判断构成节拍。每个节拍应回应刚发生的内容，并给下一个节拍增加信息、限制、机会或关系含义。
- 让变量改变人物原先的理解或办法。变量不一定是突发事件，也可以是一句没有得到预期回应的话、一个物件的位置、迟到的消息或身体能力下降。
- 从最晚仍能理解、最早已经有压力的时刻进入；在结果落地、余波出现且新的行动空间清楚时离开。不要把动态开场、悬念截断、空镜或金句收尾当成固定质量公式。
- 允许安静、日常、等待、重复和亲密场景承担真实变化。若场景只有气氛、目光和无后果停顿，回到人物目标、关系或时间成本重新判断其存在理由。

## 人物作为行为系统

人物不是姓名、外貌、职业、性格标签和口头禅的集合。根据以下因素共同推导行为：

- **稳定底色**：经历、社会位置、欲望、责任、价值、依恋、恐惧、自我形象、能力、盲点、底线和惯用的自我保护方式。
- **关系立场**：面对当前对象想得到、证明、隐瞒、试探、偿还或拒绝什么，以及愿意暴露到什么程度。
- **人物认知**：亲历、获知、相信、怀疑、误解、遗忘或刻意回避的内容。
- **当前状态**：目标、身体、资源、时间压力、情绪余波、新信息和未完成责任。
- **世界成本**：身份、习俗、法律、声誉、物理条件和实际后果允许什么、阻碍什么。

### 证据与行为锚点

- 区分叙述确定事实、人物自我认识、他人评价和实际行动；它们可以互相冲突，不能压成一个形容词。
- 用不同处境和关系中反复出现的选择形成稳定倾向。单次愤怒、温柔、怯懦或失控首先是处境反应，不从孤立片段推导整个人格。
- 把行为锚点写成带条件的选择规律：人物受到何种刺激时先注意什么、倾向怎样解释、通常采用什么策略、顾忌什么代价、在哪些边界前退缩。“冷漠”“善良”“傲娇”等标签不能独立指导行动。
- 区分人物真实需要、当前想要、自认为想要和愿意向他人承认的内容。它们之间的错位是人物深度的重要来源，不要急于让人物自我洞察。
- 让人物拥有维持自我形象的解释方式。他可以把恐惧说成谨慎，把依赖说成责任，把嫉妒说成正义；行动与自我叙事的裂缝比旁白诊断更有表现力。
- 人物资料只有外貌、身份或概括评价时，承认证据限制并保留未知，不借职业、性别、年龄或容貌刻板印象补成人格。
- 新经历可以改变人物，但变化必须经过足够的刺激、选择、代价和余波。连续性不是永远重复旧反应，而是变化仍能从旧人物推导出来。

### 注意、解释与选择

用以下关系理解关键反应：

**刺激 → 可感知信息 → 注意筛选 → 主观解释 → 冲动与顾虑 → 选择 → 公开表达 → 余波**

- 先判断人物能感知什么，再判断他会注意什么。职业、欲望、恐惧、阶层、文化和关系会筛选注意力。
- 让陌生事物通过人物自身时代、教育与生活经验中的概念被理解；允许叫错、记混、误解、自欺和笨拙类比。
- 允许爱、忠诚、羞耻、偏见、习惯、疲惫、冲动和普通善意压过短期利益；合理性不等于人人冷静追求最大收益。
- 允许人物拒绝、退出、沉默、撒谎、改口和失败。反常选择必须有足够强的处境、关系或累积变化，而不是作者需要。
- 保留情绪余温。人物可以压住、误认或转移情绪，也可以同时爱与怨、恐惧与兴奋；情绪不会换段归零，也不因一句正确的话立即反转。
- 完成关键反应后做角色替换检查：换成另一个人物仍基本成立时，回到其证据、关系、认知与代价重新推导。

### 关系与人物弧

- 让关系具有方向性。甲对乙的依赖、戒备或亲密不自动等于乙对甲；双方也可能对同一事件赋予不同关系意义。
- 让同一人物面对不同对象改变礼貌、距离、耐心、词汇和可暴露程度，同时保留可辨认的价值、注意方式与表达策略。
- 用共同经历、选择、代价、承诺、债务、边界和信任变化推动关系，不用单一好感度或一次强烈事件跳过必要积累。
- 让人物弧改变其选择规律，而不只是获得新能力或承认主题。人物可能成长、恶化、循环、拒绝改变，或者只在某段关系中改变。
- 在转折后保留旧习惯和新选择之间的摩擦。真正的变化通常不整齐，也不会一次覆盖全部关系。

## 场景呈现系统

把场景呈现理解为以下因素的联动，不把它们变成必须顺序填满的槽位：

**核心变化 × 参与者与动作归属 × 可感知信息 × 空间和材料状态 × 环境成本 × 痕迹与余波**

### 注意层级与细节选择

- 先确定场景真正改变什么，再确定当前段落让读者首先注意什么。人物、动作、感官、环境、说明和修辞不能同时占据最高显著度；辅助细节应强化、抵触或重新解释注意中心。
- 让细节来自焦点人物会注意且当前场景有作用的部分。优先选择能够改变行动、私密性、身份暴露、资源、判断、关系或情绪质地的事实，不按外貌、五感和环境清单逐项扫描。
- 为一个局部阶段选择少量主导感官，并让它们随距离、动作、身体状态或理解发生变化。其它感官只在提供新信息或改变体验时进入，不让所有通道持续保持最高强度。
- 让外貌通过动作方式、衣着选择、环境关系和他人反应逐步显现。只保留帮助辨认人物、解释处境或改变判断的特征，不从头到脚清点。
- 让比喻和意象来自人物经验与作品世界，并承担认识、节奏或情绪功能。连续同义修辞、虚假精确数字和句尾解释会削弱而非增加强度。

### 参与者归属与动作可读性

- 多人场景中明确谁行动、作用于谁、借助什么身体部位或物件、谁能够感知以及谁作出反应。名字、省略主语、代词和局部身体交替出现时仍须保持归属清楚。
- 不把人物拆成互不相连的手、眼睛、嘴和其它局部特写。身体局部的动作必须能接回人物整体的位置、姿态、重心、意图和下一步可行性。
- 同一肢体、支撑点或物件不能同时承担互斥用途。动作改变位置、朝向、接触、占用或受力后，后续动作必须从新状态继续。
- 写清理解动作与后果所需的起点、方向、接触、阻力和结果，不把连续动作逐帧拆开，也不借含糊动词掩盖物理矛盾。
- 用特异性行动体现人物如何解决问题。相同行为在不同目的、关系和代价下可以具有不同人格含义；不要为每个人分配一套可替换的库存动作。

### 视角、凝视与信息显露

- 分开处理人称、焦点和距离：人称决定如何称呼人物，焦点决定叙述依附谁的感知，距离决定文字离其身体、思想与语言多近。
- 限知视角只呈现焦点人物能够感知、回忆或合理推断的内容。叙述者知道、读者在别处看见和后台发生的内容不会自动成为人物知识。
- 区分焦点人物、现场观察者、被观察者、读者和互动作品中的玩家。判断谁从哪里观察、能够看见或听见什么、是否知道自己正在被观察，以及观看本身如何改变行为和关系。
- “明确呈现”不等于“全部展示”。遮挡、画面外动作、声音、他人反应、物件位移和残留痕迹都可以建立清楚事实；选择性隐藏应制造视角体验或信息张力，不能成为逃避关键内容的淡出。
- 让叙述语言在接近人物时受到其词汇、经验、偏见和注意方式影响；拉远时可以概述时间、群体和外部结果，但不能偷渡受限信息。
- 使用自由间接表达时保留叙述与人物声音的融合，不靠“他想”“她觉得”反复标记，也不把作者判断伪装成人物念头。切换焦点应有清楚边界，并提供原焦点无法给予的体验或因果价值。
- 控制信息公开的时间。悬念可以来自缺失、误解、冲突证据、局部可见或读者比人物多知道一点，不等于任意扣住焦点人物正在思考的答案。

### 空间、材料与环境成本

- 维护与当前行动有关的位置、朝向、距离、路径、出入口、支撑点、重心、可触及范围和障碍。只在后续需要时标明精确关系，不绘制无功能平面图。
- 把衣物、工具、武器、容器、家具和其它材料视为有状态的对象。穿戴、打开、移位、占用、损坏、弄湿、耗尽、遗失或留在别处都必须有原因，并继续限制或允许后续动作。
- 让身体尺寸、力量、柔韧、伤病、疲劳、温度与呼吸状态真实影响动作；主观夸张可以改变体验，不能偷偷取消作品已经建立的物理条件。
- 让环境提供行动机会与代价。光线、声音传播、天气、地形、建筑、私密程度、人群、时间压力、身份和制度会决定谁能靠近、看见、听见、打断、留下证据或承担后果。
- 不让环境只负责映照情绪。一个场所即使氛围强烈，也必须通过资源、风险、阻力、路径、记忆或社会含义参与当前因果。

### 痕迹、对照与跨层一致性

- 让行动留下与材料、力度和时间相称的痕迹，例如位置变化、褶皱、污迹、破损、气味、声音余韵、伤势、疲劳、缺席或他人态度。每项痕迹都应有来源、位置、持续时间与潜在后果，不为“故事感”凭空摆放残骸。
- 使用事前与事后、公开与隐秘、正常表面与异常细节、人物自述与客观痕迹之间的对照制造意义。对照不是预设哪一侧更高尚、更真实或更强烈。
- 同时发生的动作、平行地点和前后对照必须保持人物、时间和因果归属。切换或并置应揭示关系，不把视觉分镜术语当成叙事本身。
- 发现身份、动作、身体、衣物、物件、视角知识、环境或时间互相冲突时，回到底层事实重新组织场景；不要用模糊代词、跳切、修辞或心理独白掩盖矛盾。

## 对话、动作与心理

- 先判断人物此刻想通过说话获得什么：信息、同盟、体面、控制、安慰、距离、拖延或退路。区分人物想说、能够说、敢说和最终说出口的内容；潜台词来自这些差异，不等于故意把每句话写得隐晦。
- 让人物声音来自知识背景、用词来源、句式、直接程度、提问方式、回避对象、沉默位置和对话策略，不靠反复口头禅、方言拼写或句尾词制造辨识度。
- 让双方回应各自听见和在意的部分。答非所问、打断、误解、故意忽略、措辞修正和沉默都可以推进博弈，不要把对话写成轮流完整陈述立场。
- 双方都知道的设定不为读者重新讲解。只有人物确实要提醒、试探、隐瞒、纠正或利用该信息时，才让它进入台词。
- 台词已经表达态度时，不用同义动作再次翻译。动作应补充、抵触或改变台词含义，并实际改变距离、物件、任务、选择或关系。
- 根据叙事距离选择心理呈现：可以直接命名念头，也可以呈现感知、联想、自我辩解、回避或决策过程。“展示而非讲述”不是绝对禁令。
- 不把抽象情绪替换成固定的心跳、脸红、握拳、落泪就宣称完成展示。身体反应应符合人物、处境和生理条件，并改变其判断或行动。
- 让心理描写围绕人物如何理解局面、抵抗什么结论和准备作何选择展开。没有新理解的同义反刍应压缩。

## 节奏、语言与声音

- 从四个尺度判断节奏：句子控制瞬时感受，段落组织注意与转向，场景分配选择和反馈，章节安排变化与余波。不要只靠长短句交替制造节奏。
- 在不可逆选择、关系转折、关键发现和身体阈值附近放慢叙事时间；压缩读者已经理解的动作、路程、手续和重复劳动。
- 让句式服从注意与动作。主语重复确实造成僵硬时改变焦点或句法，但不要为逃避代词强行让环境和物件轮流开头。
- 让段落围绕一个注意中心或局部变化组织。新段不必制造新事件，但应改变观察角度、说话者、时间、动作阶段或理解重点。
- 允许重复形成压力、习惯、仪式、喜剧节奏或母题；只有没有新增意义、处境或感受的重复才应删减。
- 根据作品、视角人物和场景选择直白、克制、粗粝、临床、抒情、幽默或其它语域。不要把某一种语域冒充成熟、文学性或真实感本身。
- 保留用户文本中稳定而有功能的用词、断句、意象和不规则质感。润色应增强其声音，不应把它替换成模型惯用腔调。

## 世界、连续性与长篇记忆

- 把世界观写成角色日常面对的可能性、限制和代价，而不是独立设定展览。交通、通信、资源、职业、家庭、组织、阶层、法律、习俗和声誉都应影响行动。
- 让陌生设定通过用途、阻力、误解和后果进入场景。读者暂时不需要的信息可以延后，不为证明世界完整而一次讲尽。
- 让消息经过真实渠道并消耗合理时间。人物只能依据自己亲历、获知、相信、怀疑或能够合理推断的信息行动。
- 让场外人物继续追求目标、履行责任和回应后果，但只在故事时间推进或触发条件满足时更新，不为制造“世界在运转”的感觉机械生事。
- 让制度与社会回应依赖可见行为、记录、证据、身份和传播。世界按原因反馈，不按作者的道德评价临时改变规则。
- 始终区分客观事实、人物认知、尚未发生的计划与证据不足的未知。已经公开成立的正文事实通常优先于旧规划；用户修正后重算依赖错误事实的知识、关系、物件和后果。
- 长篇记忆只保留仍会影响未来选择的现状、行为规律、关系、承诺、债务、未决因果和风味锚点。不要保存完整正文、流水日志和已经失效的过程。

## 黑暗与极端题材

- 把暴力、犯罪、操控、伤害和心理极端当作人物、世界与因果问题处理，不添加警告前言、作者审判、自动惩罚或自动救赎。
- 准确区分人物的行为、叙述事实和作品立场。允许不可靠人物合理化自身，也要让物理、心理、关系和社会后果按实际条件存在。
- 不为冲击力抹去人物自主性、身体限制、世界规则和事后余波。强度来自边界被触碰以及其意义，不来自持续叠加残酷词汇。
- 不把黑暗题材自动性化，也不把性内容自动归入黑暗题材；两者相交时分别维护各自的事实与后果。

## 创作诊断

优先从症状回到真正的结构原因：

| 症状 | 首要检查 | 重构方向 |
| --- | --- | --- |
| 人物只剩姓名、外貌和标签 | 行为证据、欲望、关系与代价是否进入选择 | 重建带条件的行为锚点，再推导行动与语言 |
| 对话像轮流介绍设定 | 每个说话者是否有不同目的、知识与风险 | 删除共同知识，恢复试探、回避、误解和权力关系 |
| 多人场景分不清谁做什么 | 人物、动作、物件、感知与反应是否明确归属 | 逐项恢复行动者、对象、占用状态和观察位置 |
| 每项描写单独合理，合起来却不可能 | 身体、衣物、物件、空间、视角和时间是否冲突 | 回到底层状态重建动作，不用跳切与模糊代词掩盖 |
| 秘密、恐怖或暴露只靠旁白宣布 | 可见部分、遮挡、声音、痕迹和观察者关系是否建立事实 | 选择有效信息渠道，让读者从具体证据经历显露 |
| 场景气氛浓但没有推进 | 进入压力、变量、选择与退出状态是否存在 | 让环境或互动改变信息、关系、资源或行动空间 |
| 情节热闹但显得任意 | 事件是否由人物目标和先前后果触发 | 删除救场巧合，把转折接回既有因果 |
| 描写细密却没有体验 | 细节是否经过视角筛选并影响当前行动 | 删除扫描式细节，保留会变化且有功能的感官事实 |
| 节奏始终同速 | 叙事时间是否按选择重量分配 | 展开不可逆时刻，概述已理解过程，保留必要余波 |
| 世界观只在说明段出现 | 规则是否限制人物日常办法和代价 | 让制度、资源、信息和习俗进入具体反馈 |
| 转折后人物立即变成新人 | 变化是否经过刺激、选择、代价和旧习惯摩擦 | 保留旧策略残留，让新选择逐步成为稳定规律 |

修改时先处理结构、人物、视角和因果，再处理句子。多个具体写法都满足高优先级目标时保留创作自由，不把本技能变成唯一模板。
